📘 1. La teoría

El comparativo correlativo sirve para decir que dos cosas cambian juntas: cuando una aumenta o disminuye, la otra también. En español es “cuanto más… más…” o “cuanto menos… menos…”.

Estructura:
The + comparativo + sujeto + verbo, the + comparativo + sujeto + verbo.

Cómo formar el comparativo

• Adjetivos cortos: +er → cold → colder, big → bigger, happy → happier.
• Adjetivos largos: more + adjetivo → more tired, more expensive.
• Cantidad: more (más) y less (menos) → the more you eat, the less you save.
• Irregulares: good → better, bad → worse, far → farther.

Reglas importantes

1️⃣ Lleva the en las dos partes.
2️⃣ Va una coma en medio.
3️⃣ No se usa than.
4️⃣ Se puede acortar: The bigger, the better. (sin sujeto ni verbo).
